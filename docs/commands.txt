# SKY130 behavioral Verilog models: sourced via a sparse submodule checkout of skywater-pdk, flattened all needed cell files (65 cell types) into one directory (sky130_flat) to avoid nested-include path issues, including the shared UDP primitive files from the models/ directory, with relative-path includes patched to bare filenames.

# Functional vs. behavioral models: switched to -DFUNCTIONAL mode (simpler procedural logic models instead of UDP/timing-table-based ones), which was the fix that got flip-flops actually producing defined 0/1 values instead of perpetual x.
# Smoke test passed: a basic testbench (tb_smoke.v) driving clk/rst_n/enable/I now shows success and O resolving to real logic values (success=0, O=00000000) rather than unknowns — confirming the simulation is functioning correctly end-to-end.
# ##########
